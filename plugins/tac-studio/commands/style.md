Run `"${CLAUDE_PLUGIN_ROOT}/bin/tacctl" style` and report the path it prints. On first use it creates a short
commented template and opens it in the default text editor. If the user describes their taste in chat instead,
write it into that file in plain lines, keeping the comment block. Don't invent taste they didn't state.
